DIGIT RANK FIX

There were two important stuck-rank cases:

1. Existing tick subscription with no first tick:
   The old watchdog only considered a feed stale when last_seen had a value.
   If the subscription existed but never produced even one tick,
   last_seen stayed None forever and the feed was never restarted.

2. Warm history but missing rank snapshot:
   The old bootstrap returned immediately once history >= min_history.
   If the process had warm history but the rank snapshot was missing,
   DIGIT SCORE could remain at WAITING FOR SERVER.

V10 repairs both conditions and prevents duplicate repair tasks.

It also creates/reuses an IDLE server session after OAuth so the passive
DigitScore feed can begin before START BOT. This session bootstrap DOES NOT
start trading and DOES NOT submit a BUY.
