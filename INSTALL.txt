RULE IMPLEMENTED

A digit can become a NEW target only when:

    V1 rank #1 score >= 9.00

Examples:

    #1 digit 6, score 12.40  -> target 6, eligible
    #1 digit 6, score 8.75   -> no target, wait
    #1 digit 4, score 9.00   -> target 4, eligible

TRADE 1

If the current V1 #1 score is below 9:
- bot stays running
- no proposal is requested
- no BUY is sent
- ranking keeps updating on canonical server ticks
- the first future rank with score >= 9 becomes the target

AFTER A LOSS

If the loss-tick V1 #1 score is >= 9:
- normal fast rerank continues immediately

If the loss-tick V1 #1 score is below 9:
- next stake is advanced once
- bot enters WAITING_SCORE_GE_9
- no proposal/BUY is sent
- every future canonical tick reranks all digits
- first V1 #1 with score >= 9 becomes the next target
- that same waiting stake is used; it is NOT multiplied again while waiting
