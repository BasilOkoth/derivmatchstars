The active Render service starts with `uvicorn app.main:app`; use the `app/` package files and `bot.html` as the runtime sources. Root-level Python files in this export are older snapshots.

The shared server engine supports DEMO and REAL sessions. Set `ALLOW_REAL_MODE=true` in the deployed service to enable REAL sessions. Start Bot runs the selected session; no per-trade REAL confirmation route is exposed. Test the full flow with a DEMO account before using REAL funds.
