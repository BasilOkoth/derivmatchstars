DigitMatchStar TailGuard Research v2 — DEMO AUTOPILOT

WHAT IT DOES
- Runs autonomous research on DEMO only.
- Attempts to select AI AUTO automatically.
- Attempts to set the visible max-trades-per-cycle control to 10.
- Starts the existing DigitMatchStar bot automatically.
- Collects up to 5 completed cycles per local calendar day.
- Stops the bot after cycle 5.
- Stops immediately if a REAL account is detected or the account cannot be proven DEMO.
- TailGuard remains shadow-only: Entry/T3/T5/T7 decisions are recorded but do not yet block live/demo trade progression.
- All actual trade execution remains inside the existing DigitMatchStar bot.

INSTALL
1. Upload:
   tailguard-research-v2-autopilot.js

2. In production bot-obfuscated.html, use this order near the bottom:

<script src="/tailguard-research-v2-autopilot.js"></script>
<script src="/screen-recorder-safe-v5-2.js"></script>

3. Remove the old tailguard-research-v1.js loader if present.
4. Keep screen-recorder-safe-v5-2.js exactly once.

IMPORTANT SAFETY DESIGN
- Autopilot is intentionally DEMO-only.
- It will not autonomously run a REAL-money account.
- If account type is UNKNOWN it waits rather than trading.
- The 10-trade UI limit is set only when a matching visible numeric control can be identified.
- If the core bot exposes no identifiable trade-limit control, verify the bot's own maximum remains 10 before using the research session.

RESEARCH FLOW
Each local day:
- confirm DEMO
- confirm/select AI AUTO
- start bot
- observe TailGuard Entry/T3/T5/T7 states
- count completed cycles
- stop after 5 completed cycles
- keep data in browser localStorage
- next local day, the counter resets automatically if the page remains available

BUTTON
The small "TailGuard Autopilot" panel includes Pause/Resume.

EXPORT
Use the existing TailGuard Research panel's "Export research" button when you want to send the accumulated dataset for analysis.
