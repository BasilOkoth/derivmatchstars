WHAT CHANGES
- Every V1 ranking snapshot is stamped with rank_epoch.
- Shadow uses the same canonical rank epoch.
- NEXT target is stamped with target_epoch.
- The server snapshot exposes the canonical tick epoch/digit/quote inside digit_score.
- Each browser canonical tick immediately requests fresh server state instead of waiting only for the 250 ms periodic poll.
- Short retries (45/110/220 ms) handle the case where the browser sees the Deriv tick slightly before the server.
- A Canonical Tick ↔ Rank Sync strip appears inside the Digit Score panel.
- EXACT SAME EPOCH ✓ means browser tick, server tick, V1 rank, shadow and NEXT target all refer to the same canonical epoch.
- The already-open contract target remains frozen. This package does not alter trade placement or settlement logic.
