Trading logic in this build:
- 1.15x multiplier remains user configurable.
- Max Trades is user configurable; default shown in UI is 15 and minimum is 1.
- Server scores digits 0-9 from canonical tick history.
- Selected digit is traded for a maximum of 3 failed attempts.
- After the 3rd loss, the failed digit is excluded for the immediate rescore and a new target is selected.
- The stake progression continues across target recycling.
- Exact next eligible tick decides local WIN/LOSS immediately.
- Official Deriv settlement remains background reconciliation/accounting.
- WIN stops the cycle immediately.
- FAST_WON triggers win sound in the UI.
- FAST_WON/WON uses the existing Telegram publisher.

Scoring feature families used:
- digit gap (moderate-gap weighting, not endless overdue chasing)
- frequency 5 / 10 / 25 / 50 / 100
- entropy 10 / 25
- adjacent repeats
- one-step transition
- two-step sequence/DNA transition
- short-vs-long frequency divergence
- cluster pressure
- current-digit equality
- SAFE-TICK-style low-frequency + entropy state

IMPORTANT
This build is intended for DEMO testing first. Scoring ranks candidates; it does not guarantee that a selected digit must win.
